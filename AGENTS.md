# Belisk — working notes

Belisk — combat meter and companion for AION 2, aimed at the global servers. A native GPUI
overlay on a Rust capture/parse/DPS core. Started from
[Aether](https://github.com/Helveticxa/Aether-Aion2-DPS-meter-Global), itself a fork of
[NOIA2](https://github.com/ZDYoung0519/NOIA2) (GPL-3.0); both are only the baseline,
and nothing is merged from them. The Tauri + React app was removed on 2026-10-04;
tag `tauri-final` is its last commit.

[docs/technical-notes.md](./docs/technical-notes.md) records how the capture, parsing,
recording and saving code works and why, and how the app side works (distribution,
overlay windows, fonts, translations, the meter's model, secondary windows, settings,
reminders, the toolbar). Approved designs: `docs/gpui-mockups/approved/`.

`build.rs` copies `crates/app/windivert/*` beside the exe in `target/<profile>/`
(and embeds the manifest and icon), so a fresh `cargo run` finds `WinDivert.dll`.

Dependencies (GPUI and its layout, text and image crates) build optimized in dev
and test builds (`[profile.dev.package."*"] opt-level = 2` in the workspace
`Cargo.toml`), the workspace's own crates unoptimized: a cold build takes about
twice as long, later builds do not (docs/technical-notes.md, "Debug builds").

## Conventions

- **Comments and logs in English**, everywhere.
- Files use **CRLF** with `core.autocrlf=true`. Scripts that rewrite files must preserve CRLF, or the diff becomes a whole-file rewrite.
- Forward slashes in paths inside Rust strings.
- **User-facing text goes through i18n**: `fl!("area-key", arg = value)` from `crate::i18n`, with the message in both `crates/app/i18n/en/belisk.ftl` and `fr/…`. No English words in `format!` or string literals that reach a window, a clipboard report or an accessibility label; skill and mob names and the dungeon label are looked up by id in the language in force (`game_data::skill_name`, `game_data::mob_name`, `game_data::dungeon_of`, French from `*_names_fr.json` and `dungeons.json`, English where an id or field has no French name), while the core and the saved records keep English. The test `i18n/tests.rs` fails when the two files differ in keys or arguments.
- Moving the project directory requires `cargo clean` — Cargo bakes absolute paths into `target`.
- **Branches and releases.** Work happens on `dev`; a merge (push) to `main` whose `crates/app/Cargo.toml` version has no tag yet is the release, built and signed by GitHub Actions (docs/releasing.md). Raise the version and rename the top section of both changelogs in the same change.

## Things that will bite you

- **Elevation.** The exe's manifest demands Administrator (capture needs it); a
  `probes` build is `asInvoker`. Tests live in the library and run unelevated.
  Never run the release exe from an agent session: the user may be playing.
- **Never touch a game's process.** No `OpenProcess` on another program, no
  `sysinfo` refresh of all processes, no injection, input or hooks. WinDivert
  is opened only when Npcap cannot capture, and unloaded when the last handle
  closes. See docs/technical-notes.md, *Staying clear of anti-cheat*.
- **WinDivert files must ship.** A release needs `WinDivert.dll` and
  `WinDivert64.sys` beside the exe. The DLL is delay-loaded (`build.rs`:
  `/DELAYLOAD:WinDivert.dll`), so the meter starts and captures with Npcap when
  they are absent; the guard in `windivert_capturer.rs` loads the DLL before
  the first WinDivert call, and without it WinDivert is just unavailable. They
  drifted out of a release once while working for whoever built it.
- **Region profiles are load-bearing.** A server id is used *structurally* to
  locate fields inside player-info packets; the profile is always `Auto`.
- **No blocking in the meter's threads.** The core calls `EventSink::emit` on
  its own threads; the sink must not block. UI work goes through `bridge.rs` to
  the UI thread, never a window call from the meter thread.
- **Recordings keep both names.** New recordings are `.belisk` with the magic `BELISKRC`;
  `.aetherpc` / `AETHERPC` version 1 (the 12-byte header and records are the same) stays
  readable forever by replay, packet-explorer and the Settings list, and rolling pruning counts
  both. `recorder::is_recording_path` is the one place that knows the extensions; a test decodes
  a fixed `AETHERPC` file, so never let it stop passing. Tests and tools use temp folders, never
  the real `%APPDATA%\Belisk` or the old `com.helveticxa.aether` folder.
- **There is no cloud.** No accounts, uploads or leaderboards.
- **English and French only.** Bundled data carries no Chinese: `npc_names_en.json` is
  built by `scripts/build-npc-names.mjs` from Kuroukihime's GPL data, `npc_names_fr.json`
  and `skill_names_fr.json` by `scripts/build-fr-names.mjs`, and a test fails if a Han
  character appears in either NPC file. Regenerate rather than edit by hand.
- **Never run the release or elevated app, or launch the game, in agent work.**
  Visual checks go through `--features probes --capture`, which renders off every monitor.
