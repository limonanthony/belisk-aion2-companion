Player detail round 2 exploration

  • Everything the current detail window shows: identity, server and combat power; live or history mode; damage, DPS, fight time and hits; the seven hit types; per-skill hits, rates, multi-hit damage, min, max, average, total and spec; player and boss buffs with caster, coverage and whether they are still up.
  • The open choice is the skill table, which has 15 columns today. a: four columns and a row that opens for the rest (recommended). b: every column at once, in a 1000 px window. c: two tabs, Damage and Hit types, sharing the skill column.
  • Skill rows are the meter's soft bars in the player's class colour, scaled by damage; buff coverage uses the caster's class colour. No frosted glass: GPUI cannot blur behind one element, so the window is the same warm card as the meter.

Behaviour carried over

  • Opens from a meter row, a PvP damage row, or a player inside a history record (history mode, frozen data). Live mode follows the player's current target.
  • Buff panels are collapsed by default and keep their open or closed state while the window lives. Active buffs sort first, then by coverage.
  • Multi-hit damage shows its breakdown (2 hits, 3 hits…) on pointer over, as a tooltip today.

GPUI notes

  • The current window uses backdrop-filter: blur(18px); GPUI can only blur the whole window background, so the design does not rely on it. A whole-window blur could be an option later, not a dependency.
  • Skill and buff icons are the game PNGs (multi-colour images are fine as images). The combat power mark is the existing profile_power_icon_pc.png.
  • Scrolling lists use GPUI's own scroll container; the thin thumb shown is drawn by it.
