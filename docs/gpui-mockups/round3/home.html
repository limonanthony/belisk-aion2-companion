Round 3 Startup gate Home Settings Approved

Home round 3 exploration

  • Home does one job: start the meter and say what it is doing. One card: the status, the character and server once found, elapsed time, the one bright button, and "Close this window once it starts". The shortcuts you need in game sit beside it.
  • Open choices. Navigation (shared with Settings): a, a sidebar with Meter and the settings sections (recommended); b, top tabs; c, two tabs in the title bar, Settings as one scrolling page with an index. Connection details: a, one line in the card (recommended); b, four status tiles beside it.
  • The Language control switches the shell and Home to French, to check that the strings fit (French runs 20–30% longer).

Behaviour carried over

  • Start opens the meter overlay. With "Close this window once it starts" on (the default), the main window closes and the meter keeps running from the tray; the old system notification is dropped.
  • A failed start says which capture backend failed and why, inline in the card, with the capture check one click away. It stays until the next attempt.
  • Elapsed time counts from Start and survives the window being closed and reopened.

GPUI Kit notes

  • Kit pieces: TitleBar, Sidebar (nav a) or Tabs (b, c), Button, Switch, Badge/Tag, Kbd, Alert-style inline message (or a styled div if the Kit version has no Alert).
  • No background artwork or video: the canvas is the warm near-black of the overlays, opaque.
