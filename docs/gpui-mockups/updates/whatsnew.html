What's new mockup round 2026-10-09, not approved

  • Agreed After an update, a "What's new" view shows only the versions newer than the last one this player ran, up to the current one (skipped versions included), from CHANGELOG.md / CHANGELOG.fr.md, rendered natively in the app's look, in the player's language.
  • Proposed Where: an overlay window of its own with History's frame (370 px, header, close, footer), opened once, by itself, on the first start of a newer version, 6 px under the toolbar with left edges aligned (above it when the toolbar sits low), like the reminder card while the meter is closed. It never takes the keyboard (no-activate, as every overlay tool), scrolls with the wheel, and stays until you close it. It is not a toolbar tool: no icon, nothing to keep open.
  • Proposed Not chosen: a card like the reminder card (too small for several versions, and a 30 s lifetime does not suit reading); an icon in the toolbar only (easy to miss, one more thing that lights up).
  • Proposed When not: never during a fight: it waits for the fight to end, then opens (TASK-29's rule). A fresh install shows nothing. A version whose entry has no bullets does not open it. The version counts as seen once the window is closed (× or "Full changelog"); quitting with it open shows it again at the next start.
  • Versions and text are invented. The build runs 1.6.0 after the update; "since 1.4.0" shows what a player who skipped two versions sees.

Layout

  • Header: Lucide scroll-text and "What's new", a chip-good "Updated to 1.6.0" (Lucide check), close. With more than one version, a faint line under it: "Since 1.4.0, the last version you ran".
  • Each version, newest first: the version 13.5 px / 600 and its date in faint on the right; the summary paragraph 12.5 px / 500 in text; the bullets 12 px / 500 in muted with a 4 px faint dot; 14 px between versions, no rules. Bold is 600 in text.
  • The list scrolls inside the window past 318 px (the 3 px thumb in its gutter); the window hugs shorter content.
  • Footer: a quiet text button "Full changelog" (Lucide settings and chevron-right) that opens Settings › About › Changelog and closes this window.

The Markdown subset Proposed

  • ## [1.6.0] - 2026-10-21 headings, one summary paragraph, - bullets (one level; a bullet may wrap onto lines indented by two spaces), and **bold** inside the summary and bullets. Nothing else.
  • Bold yes: it names a feature or a setting path ("**Settings › Reminders**") and costs one font weight. Inline code no: players never need it. Links no: a click in a no-activate overlay would open a browser over the game; the full notes are on GitHub anyway.
  • The app's parser fails on anything else, and cargo test parses both files with it and checks parity (same versions, same bullet counts), as the state "The subset" shows with this page's own parser.
