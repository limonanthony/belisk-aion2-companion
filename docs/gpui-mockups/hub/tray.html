The tray icon hub round, 2026-10-08, not approved yet

  • Kisk keeps an icon in the Windows notification area (the app's icon, crates/app/windows/icon.ico), so the toolbar can come back after Alt+Shift+CapsLock hid it, and Kisk can be quit from there.
  • Windows draws the tooltip and the menu itself, in its own light or dark theme; the taskbar corner here is only a stand-in. Tags: Agreed, Proposed; README.md lists every decision.

Behaviour

  • Agreed Menu: "Show toolbar" and "Quit".
  • Agreed Closing the toolbar quits Kisk, as Quit does: every tool closes and the process ends (closing the main window must end the process).
  • Agreed Show toolbar brings back the toolbar and every tool that was open, as Alt+Shift+CapsLock does.
  • Proposed A left click on the icon does the same as "Show toolbar" (the menu's default item, in bold, as Windows draws defaults). It also unfolds a folded toolbar and brings it in front.
  • Proposed Tooltip: "Kisk". The menu is only those two items; Settings and the tools stay on the toolbar.
  • Proposed No Windows notification, ever (as the reminder card: the game keeps the screen).
