What's new approved 2026-10-09 (updates and the changelog)

  • After an update, What's new shows only the versions newer than the last one this player ran, up to the running one (skipped versions included), from CHANGELOG.md / CHANGELOG.fr.md, drawn natively in the app's look, in the player's language. The whole history is in Settings › About › Changelog.
  • Where: an overlay window of its own with History's frame (370 px, header, close, footer), opened once, by itself, on the first start of a newer version, 6 px under the toolbar with left edges aligned (above it when the toolbar sits low), like the reminder card while the meter is closed. It never takes the keyboard (no-activate, as every overlay tool), scrolls with the wheel and stays until you close it. It is not a toolbar tool: no icon, nothing to keep open.
  • When not: never during a fight (it waits for the fight to end, then opens). A fresh install shows nothing. A version whose entry has no bullets does not open it. The versions count as seen once the window is closed (× or "Full changelog"); quitting with it open shows it again at the next start.
  • From an older build: a settings file from before the 1.0.0 reset has no last-seen version; it counts as coming from before 1.0.0, so 1.0.0's notes show once.
  • Decided with the user in the updates round (updates/README.md, the record of how it was chosen). Values are in tokens.md, "Updates and the changelog". The version resets to 1.0.0; the later versions and the changelog's text are invented. The build runs 1.6.0 after the update; "since 1.4.0" shows what a player who skipped two versions sees.

Layout

  • Header: Lucide scroll-text and "What's new", a chip-good "Updated to 1.6.0" (Lucide check), close. With more than one version, a faint line under it: "Since 1.4.0, the last version you ran".
  • Each version, newest first and all open: the version 13.5 px / 600 and its date in faint on the right; the summary paragraph 12.5 px / 500 in text; the bullets 12 px / 500 in muted with a 4 px faint dot; 14 px between versions, no rules. Bold is 600 in text.
  • The list scrolls inside the window past 318 px (the 3 px thumb in its gutter); the window hugs shorter content.
  • Footer: a quiet text button "Full changelog" (Lucide settings and chevron-right) that opens Settings › About › Changelog and closes this window.

The changelog files

  • CHANGELOG.md and CHANGELOG.fr.md (a future language: CHANGELOG.<code>.md), embedded in the build. They start at 1.0.0, the version reset; Aether's history moves out of CHANGELOG.md into a file of its own, credited to Aether, and is not shown in the app.
  • The subset: ## [1.6.0] - 2026-10-21 headings, one summary paragraph, - bullets (one level; a bullet may wrap onto lines indented by two spaces), and **bold** inside the summary and bullets. Nothing else: no inline code (players never need it), no links (a click in a no-activate overlay would open a browser over the game; the full notes are on GitHub).
  • The app's parser fails on anything else, and cargo test parses both files with it and checks parity (same versions, same bullet counts), as the state "The Markdown subset" shows with this page's own parser.
  • Dates are written ISO in the files and shown "21 Oct 2026" / "21 oct. 2026".
