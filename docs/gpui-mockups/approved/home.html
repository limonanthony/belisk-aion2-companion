Home approved, round 3

  • Home does one job: start the meter and say what it is doing. One card: the status, the character and server once found (one line), elapsed time, the one bright button, and "Close this window once it starts". The shortcuts you need in game sit beside it.
  • The sidebar holds Meter, then the settings sections, then the meter's status line. Segoe UI Variable for text; Bahnschrift for titles, figures and buttons.
  • The Language control switches the shell and Home to French (French runs 20–30% longer).

Behaviour carried over

  • Start opens the meter overlay. With "Close this window once it starts" on (the default), the main window closes and the meter keeps running from the tray; the old system notification is dropped.
  • A failed start says which capture backend failed and why, inline in the card, with the capture check one click away. It stays until the next attempt.
  • Elapsed time counts from Start and survives the window being closed and reopened.

GPUI Kit notes

  • Kit pieces: TitleBar, Sidebar, Button, Switch, Badge/Tag, Kbd, an Alert-style inline message (a styled div if the Kit version has no Alert).
  • No background artwork or video: the canvas is the warm near-black of the overlays, opaque.
