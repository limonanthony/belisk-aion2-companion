Tray icon approved 2026-10-08 (the hub)

  • Kisk keeps an icon in the Windows notification area (the app's icon, crates/app/windows/icon.ico), so the toolbar can come back after Alt+Shift+CapsLock hid it, and Kisk can be quit from there.
  • Windows draws the tooltip and the menu itself, in its own light or dark theme; the taskbar corner here is only a stand-in, not product styling.

Behaviour

  • Menu: "Show toolbar" and "Quit". "Show toolbar" is the default item (bold, as Windows draws defaults). Settings and the tools stay on the toolbar.
  • Show toolbar brings back the toolbar and every tool that was open, as Alt+Shift+CapsLock does. A left click on the icon does the same; it also unfolds a folded toolbar and brings it in front.
  • Quit, like closing the toolbar, quits Kisk: every tool closes and the process ends (closing the main window must end the process).
  • Tooltip: "Kisk". No Windows notification, ever (as the reminder card: the game keeps the screen).
