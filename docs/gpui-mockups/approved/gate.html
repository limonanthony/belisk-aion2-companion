Startup gate approved, round 3

  • A small window before the main one: Administrator rights, Npcap and WinDivert, each with one sentence of what is true now. Npcap is required only while WinDivert cannot stand in; WinDivert is always optional and stays quiet when Npcap works. An optional check that fails never looks like an alarm.
  • Blocking problems get a red-tinted row and the one fix the app can offer: Install Npcap (download, SHA-256 check against the pinned build, then Npcap's own installer window) or downloading Aether again when the bundled driver file has gone.
  • When everything required passes but Npcap is missing, the gate waits for "Open Aether" so the recommendation is read: WinDivert works, but it is a driver some anti-cheats dislike, because lag switches are built on it.

Behaviour carried over

  • The gate is authoritative in Rust: "Open Aether" asks the backend, which re-checks before showing the main window. A failure there re-runs the checks and shows the reason.
  • When it opens on its own at start-up and everything passes, it continues after 1.2 s, except when Npcap is missing: then it waits for "Open Aether". Opened again from Home ("Re-run capture check"), it never continues by itself and offers Close instead of Quit.
  • With Npcap working, WinDivert is judged by its file alone and never loaded: some anti-cheats treat a loaded WinDivert as a warning sign, because lag switches are built on it.

GPUI Kit notes

  • Rows are plain styled divs (no Kit component needed); buttons are Kit Button. The spinner is Kit's Indicator or a rotating Lucide loader-circle (a transform animation; GPUI animates rotation through with_animation).
  • The window is a borderless GPUI window with Kit's TitleBar (close only); it is not resizable.
