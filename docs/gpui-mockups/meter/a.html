A: Ledger dense table, numbers first

  • A spreadsheet for players who read figures: fixed, labelled columns, monospaced digits, ten rows in about 230 px.
  • Colour is information only: class colour lives in a 2 px rule under each row, green and rose mean pace, everything else is graphite.
  • Each row carries its own dark plate, so the table stays readable when the background opacity is turned down over a bright scene.

Intended motion

  • Figures swap in place, no counting: monospaced digits keep every column still, so there is nothing to animate.
  • Rank change: rows slide to their new slot over 160 ms (ease-out). Bars change width over 200 ms. Nothing else moves.
  • Pointer over: header meta cross-fades to the tool buttons in 100 ms; the window does not resize. Capsule expands in one step, no height tween.
  • Frames are drawn only when a snapshot arrives or a tween is running; no idle animation, no pulsing live dot.

GPUI notes

  • All fills, the 1 px border, rounded corners and the drop shadow map to bg, border_1, rounded and shadow. Rows and bars are plain divs; the bar is an absolutely positioned child with a relative width.
  • Fonts: Cascadia Mono (falls back to Consolas) for figures, Segoe UI Variable Small for names. Both are system fonts on Windows 11; nothing is bundled.
  • Uppercase labels are uppercased strings, not a text transform. No letter spacing is used.
  • Class icons are the existing PNGs in public/aion2/class/, drawn as images. Every other icon is a single-colour Lucide SVG.
